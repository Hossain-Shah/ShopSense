# ShopSense

## Purpose:
- Invoice record with automated AI approach

## Dependency:
  - ocr.py deals with text information extraction from image/scanned document
  - ner.py deals with text information labelling to their category
  - extract.py deals with text information relation mapping to their category
  - main.py deals with API code

## Technology:
- pytesseract‎
- pillow
- spacy‎
- fastapi
